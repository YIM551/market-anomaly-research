# 공개 자료와 원본 보존

사용자가 개인 연구의 코드·문서·논문·결과 공개를 허용한 범위에서 정리했습니다. 원래 모델 알고리즘과 Notebook 셀 흐름은 보존했습니다.2026년의  문서·검사기 추가를 과거 개발 commit으로 꾸미지 않았습니다.

공개한 자료는 경로를 정리한 소스·Notebook, 저장 수치 발췌, 본인 결과 그림 10개, 개인정보와 권리 불명 삽입 그림을 제거한 연구 원고, 원문을 포함하지 않는 입력 품질 집계, 오탐 예시, 새 검사기와 테스트입니다.

외부 뉴스 본문·요약·증강 CSV, 제3자 문헌 PDF, 일반 AE 구조 그림, 개인정보가 있는 원본 PDF/HWPX/PPTX/ZIP, 개인PC 경로가 포함된 Notebook 경고 출력은 제외했습니다. 발표 자료의 외부 그림과 기획안은 구현 증거로 사용하지 않았습니다. 대표 그림의 원본 이름과 SHA256은 [자산 출처](assets-provenance.json)에 기록했습니다.

개인 실명은 현재 README에서 제거했습니다. 이미 공개된 과거 commit의 README에는 해당 표현이 남아 있을 수 있습니다. 이 작업은 과거 이력을 재작성하거나 force push하지 않았습니다.

권리 범위가 확정되지 않은 외부 자료에 임의의 MIT/Apache 허가를 부여하지 않았습니다. 별도 LICENSE가 없다는 것은 자유로운 재배포 허가를 뜻하지 않습니다. 저자 벤치마크 저장소의 GPL 표시를 이 저장소 전체에 자동 적용하지 않았습니다.

# 데이터 출처와 입력 품질

## Source / Usage

| 자료 | 출처·식별자 | 형식/사용 | 라이선스·재현 상태 |
|---|---|---|---|
| 거래량 | 코드의 yfinance `Ticker.history` | Date/Volume, 5종목 | 원본 시세 스냅샷 없음, 재요청 가용성/조건 확인 필요 |
| 이상 구간 | Tallboys 등 연구의 5종목 구간을 코드에 기입 | 시작/끝 timestamp→이진 라벨 | [저자 저장소](https://github.com/zhuye88/ADMA21), 외부 원본 복제 없음 |
| 뉴스 | 로컬 CSV, 개별 Source URL | 제목/요약과 날짜, 일별 감성 | 문서에 GPT 심층 리서치로 수집했다고 설명. 원문·생성 과정·재배포권 미확정 |
| 증강 | 원고에 동의어·파라프레이즈·문장 재구성이라고 설명 | 뉴스 제목/요약 변형 | 생성 코드·원문 연결 ID·검증 로그 미복구 |
| 감성 모델 | `ProsusAI/finbert` | 사전학습 분류기 추론 | 정확한 revision 미복구, 자체 파인튜닝 기록 없음 |

원본 뉴스 export는 `제목,1열,2열,3열` 구조입니다. 모델 입력은 별도 증강 CSV의 `Date,Headline,Summary`를 요구합니다. 현재 코드가 Kaggle 또는 Hugging Face의 특정 뉴스 dataset ID를 직접 내려받았다는 근거는 없습니다.

## 확인한 규모

| 종목 | 원본 CSV 행 | 증강 레코드 | 기존 로더가 읽는 행 | 고유 날짜 | 증강 날짜 범위 |
|---|---:|---:|---:|---:|---|
| AEMD |19|131|131|18|2023-08-14~2025-05-14|
| APPB |14|58|58|13|2019-01-03~2020-04-27|
| GME |10|36|35|9|2020-08-31~2021-04-26|
| NBDR |9|31|31|7|2019-01-29~2020-04-03|
| TRBO |7|24|24|6|2019-04-02~2020-04-16|
| 합계 |59|280|279|종목별 합53| |

2026-09-10 로컬 파일을 읽어 센 레코드 수입니다. 증강 문장은 독립적인 원본 기사 수가 아닙니다. 시세 row 수·파일 크기·class 비율은 원본 시세가 고정 저장되지 않아 미확인입니다.

## 발견한 결함

1. **AEMD 시점:** 뉴스가 2023~2025년인데 라벨은 2020년이고 시세 요청은 2018~2021년입니다. 결합하려는 사건과 뉴스가 겹치지 않습니다. 정확한 입력이 없으므로 과거 뉴스 내용을 임의로 다른 날짜에 배치하지 않았습니다.
2. **AEMD 헤더:** 제출본은 `date,headline,summary,source`로 코드와 대소문자가 다릅니다. 주변 폴더에는 대문자 헤더와 다른 인코딩의 131행 버전도 있어 어느 파일이 당시 실행됐는지 확정할 수 없습니다.
3. **GME 레코드28:** 4열 헤더에 5열 레코드가 존재합니다. 원본 `on_bad_lines='skip'`은 이 행을 조용히 제외합니다. 새 검사는 오류를 보고하며 데이터를 바꾸지 않습니다.
4. **기간·결측:** calendar union과 fillna0은 시세가 없는 날과 뉴스가 없는 날을 동일하게 취급합니다. 뉴스 공개시각이나 timezone 정합성도 미검증입니다.
5. **텍스트 인코딩:** 원래 로더가 모든 파일을 latin1로 읽기 때문에 UTF-8 텍스트를 변형할 수 있습니다. 새 검사는 UTF-8을 기본으로 하며 명시적인 encoding 선택만 허용합니다.

[실제 입력 사전 검사 결과](evidence/news-preflight.json)는 원문을 포함하지 않습니다. AEMD의 헤더/기간 오류와 GME의 열 수 오류 때문에 전체 `ok=false`가 정상적인 감사 결과입니다. 각 뉴스의 진실성·출처 권리는 이 도구가 판정하지 않습니다.

## 전처리와 다음 입력 계약

수집 시각, 기사 공개 시각, 종목, 원문 ID, 증강 부모 ID, 라이선스를 보존한 고정 스냅샷이 필요합니다. 소스별 날짜 범위·schema·기사 누락·중복을 먼저 검사하고 시간순 분할 전에 증강 계보를 분리해야 합니다. 재배포가 허용된 뉴스만 `data/raw/{TICKER}_augmented.csv`에 놓습니다. 자세한 명령은 [재현성](reproducibility.md)에 있습니다.

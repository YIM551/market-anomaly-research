# 처리 시간과 측정 범위

이 저장소는 오프라인 연구이며 웹 API의 latency, TPS, 동시 사용자 수를 측정한 자료가 없습니다.

탐색 Notebook cell17의 AE best 설정 저장 시간은 다음과 같습니다.

| 종목 | 저장 시간(초) |
|---|---:|
| AEMD |1.88|
| APPB |7.77|
| GME |1.93|
| NBDR |3.65|
| TRBO |3.06|

같은 Notebook cell15 함수에서 모델 생성·compile 후 타이머를 시작해 fit, predict, MSE와 플래그 계산까지 측정한 값입니다. 데이터 다운로드, FinBERT, 전체 pipeline 시간은 포함하지 않습니다.

하드웨어와 환경이 확정되지 않았고 반복 측정 분포도 없습니다. 따라서 처리속도 우월성, p95, TPS로 바꾸어 설명하지 않습니다. 통합 Notebook은 다른 학습 실행을 포함하므로 위 시간을 통합 모델의 실행 시간으로 인용하지 않습니다.

새로운2026년 검증은 입력 파일 검사와 단위 테스트이며 모델 benchmark가 아닙니다. [검증 범위](reproducibility.md)를 참조하세요.

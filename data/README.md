# 입력 데이터 계약

`data/raw/`는 Git에서 제외합니다. 각 `AEMD`, `APPB`, `GME`, `NBDR`, `TRBO`에 대해 `{TICKER}_augmented.csv`가 필요합니다.

필수 열: `Date`, `Headline`, `Summary`. 원본은 latin1 인코딩과 `on_bad_lines=skip`으로 읽으므로, 실제 인코딩·유실 행 검증이 필요합니다. CSV는 주가 파일이 아니라 뉴스 입력입니다. 주가/거래량은 실행 시 yfinance에서 별도로 가져옵니다.

뉴스 본문/요약과 증강 데이터는 출처·수집 방법·재배포 라이선스를 확인하기 전 제공하지 않습니다. 참고 논문 데이터셋과 yfinance 데이터가 동일하다고 가정하지 않습니다. 거래정지/상장폐지 종목의 과거 데이터 가용성은 실행 시 확인 필요입니다.
